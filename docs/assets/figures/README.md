# Final Figures

Approved figure exports belong here. Each file should map to a figure ID, exact published dataset, generating code or method, approval date, and related publication.

KID-001 article figures use responsive asset pairs:

- Landscape files are the desktop, slide and report versions.
- Files ending in `_mobile` are 1080 × 1350 portrait compositions selected automatically below 700 px.
- Both variants must reconcile to the same canonical dataset and figure ID.

See the [Kenya in Data Mobile Visualization Standard](../../../Operations/Mobile%20Visualization%20Standard.md) for layout, typography, web embedding and QA requirements.
