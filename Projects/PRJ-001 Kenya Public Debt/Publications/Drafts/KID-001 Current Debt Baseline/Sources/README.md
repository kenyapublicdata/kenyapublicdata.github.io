# Publication sources

This folder contains the release-specific source manifest and citation ledger. The project-wide discovery register remains at `Sources/Source Register.md`.

The citation ledger supports the canonical article at [`KID-001 Current Debt Baseline.md`](../KID-001%20Current%20Debt%20Baseline.md).

Every published value must identify its institution, document, edition, table or section, page, observation date, unit, status and transformation.

The October 2024 IMF/World Bank assessment is not used in this short current-baseline post; a claim about the latest debt-distress classification would require a separate freshness review.
