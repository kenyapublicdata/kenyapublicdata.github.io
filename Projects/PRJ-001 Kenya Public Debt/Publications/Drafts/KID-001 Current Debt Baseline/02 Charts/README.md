## Scope boundary

Do not use long historical series, administration comparisons, or nominal-versus-real debt charts in this quick post. A June 2025 baseline value may appear only when needed to explain the latest May 2026 observation, and must be labelled with its date.

## Publication requirements

Each released figure should include SVG, PDF and 300-DPI PNG exports, alt text, the generating script or specification, and an exact source note.
