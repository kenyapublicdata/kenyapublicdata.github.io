# Article Package — KID-001 Current Debt Baseline

This directory contains the publication-ready long-form article and assets for publication **KID-001**.

## Primary Document

- [`article.md`](article.md) — *Kenya's Public Debt: The Current Stock, Composition and Servicing Burden*

## Publication Scope & Features

- **Scope:** Verified June 2025 fiscal outturns (National Treasury) and May 2026 latest complete monthly updates (Central Bank of Kenya).
- **Core Findings:**
  - Public Debt Stock: KSh 11.814 Trillion (June 2025) → KSh 12.896 Trillion (May 2026).
  - Domestic vs. External Split: 53.5% / 46.5% (June 2025) → 56.1% / 43.9% (May 2026).
  - Debt Service: KSh 1.722 Trillion (71.2% of ordinary revenue).
  - Domestic Interest Squeeze: KSh 776.3 Billion (32.1% of ordinary revenue).
  - Statutory Anchor: 63.7% PV of GDP vs. 55% PFM Act ceiling.
- **Epistemic Standards:** Strictly neutral tone, exact document citations, granular table breakdowns.
